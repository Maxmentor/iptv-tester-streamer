# 🎬 FlixStream - M3U Playlist Tester & Cinema Player

> **FlixStream** is a modern, lightweight, single-file web tool designed to deeply test your IPTV / M3U playlists (Live vs. Dead streams) and play working channels directly inside a built-in Netflix-style cinema player.

---

## ✨ Features

* 🔍 **Deep Verification (No Fake Green):** Goes beyond simple pings by validating HLS manifests and actual video buffering, accurately tagging genuine streams as 🟢 and dead ones as 🔴.
* 🎬 **FlixCinema Pro Player:**
* Swipe Gestures for Brightness & Volume control
* Switcher for HLS Quality, Audio Tracks & Subtitles
* Playback Speed Controls (0.5x to 2.0x)
* Screen Lock & Picture-in-Picture (PiP)
* Double Tap to Fit / Stretch (Aspect Ratio toggle)


* 📥 **Clean M3U Export:** Download a fresh `.m3u` file containing only verified working (🟢) channels with a single click.
* 🔎 **Real-time Channel Search:** Instant filtering by typing the channel name or stream URL.
* 📋 **One-Click URL Copy:** Dedicated button next to every channel to copy the stream link instantly.
* 🌐 **Find M3U Link Integrated:** Direct quick-link to discover and source fresh M3U playlists.
* 📱 **100% Mobile Responsive:** Seamlessly optimized for phones, tablets, and desktop displays.
